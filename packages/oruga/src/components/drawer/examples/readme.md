The **Drawer** component is a content container overlay similar to a modal, with key difference in placement.
It is based on the [HTML \<dialog\> element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog) and can be toggled to appear from the left, right, top, or bottom edge of the viewport.
For example, the component can be used to show an overlay for navigation, shopping carts, and more.
