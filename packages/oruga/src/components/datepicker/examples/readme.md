The **Datepicker** input component allows users to select a date based on their browser’s locale from a customizable calendar, or to type the date directly into the input with full internationalization support.
The input opens a simple popover/modal for selecting a date, and can use the native datepicker on mobile devices via the `mobile-native` prop.

The overlay is implemented using the native [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API).

Use it with the [Field](/components/Field) component to access all the functionalities.
